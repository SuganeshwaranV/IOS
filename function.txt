Argument labels in Swift:

func greet(name: String) {
    print("Hello, \(name)")
}

greet(name: "Kumar")


Output:
Hello, Kumar


//Here, name is used both inside the function and when calling it.
//Using a different argument label
//You can make the function call read more naturally.

func greet(to name: String) {
    print("Hello, \(name)!")
}

greet(to: "Kumar")


Output:
Hello, Kumar!


In "to name":

- "to" is the argument label used when calling the function.
- "name" is the parameter name used inside the function.
Removing an argument label with "_"
Use "_" when you want to call the function without writing the argument label.

func square(_ number: Int) -> Int {
    return number * number
}

print(square(5))



Output:
25


Notice: that we write square(5), not square(number: 5).

Practical iOS Developer examples:

Login validation:

func validateLogin(email: String, password: String) -> Bool {
    if email.isEmpty || password.isEmpty {
        return false
    }

    return true
}

let isValid = validateLogin(email: "user@example.com",password: "abc123")

print(isValid)



Output:
true

Calculate a shopping cart total:

func cartTotal(price: Double, quantity: Int) -> Double {
    return price * Double(quantity)
}

let total = cartTotal(price: 250.0, quantity: 4)

print("Cart total: ₹\(total)")



Output:
Cart total: ₹1000.0
